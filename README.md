# LeadsPipeline

A lead marketplace where colleges and universities buy student leads using prepaid credits.

- **Normal leads**: verified contact details plus study intent
- **Gold leads**: a complete document pack prepared and checked by us
- Buyers can get a credit refund if the student enrols but doesn't complete the study. They don't get one for leads they fail to convert.
