Rules for the build
• Purchase is one DB transaction: lock the lead row, check it is still LISTED, check balance, write ledger, create Purchase, set SOLD.
• An exclusive lead is sold once. A second buyer sees "just sold" and is not charged.
• Balance = SUM(ledger.amount). Never store it as an editable number.
• A bid in the last [N] minutes extends the auction.
• No bids above reserve when it closes: the lead goes back to buy now.
• Auto-buy rules run when a lead is LISTED, for buy-now leads only.
